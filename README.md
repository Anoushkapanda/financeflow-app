# FinanceFlow

A responsive personal finance tracker with dark/light theme toggle — built with JavaScript.

🔗 **[View Live Site](https://anoushkapanda.github.io/financeflow-app/)**

---

## Features

- Track income and expenses
- Dark mode / light mode toggle
- Visual summary of spending
- Fully responsive layout

## Tech Stack

- Tailwind
- Typescript
- React
- Chart.js/Recharts
- Redux/Context API
